# Desafio 4

Desafio desenvolvido durante meus estudos no curso **Java10X** do **Horacio Fiasco**.

## Sobre

O exercício consiste em representar diferentes tipos de ninjas, utilizando classes e métodos para apresentar suas informações e executar habilidades.

A implementação utiliza uma interface `Ninja`, além de classes para ninjas básicos e avançados.

## Conceitos praticados

- Interfaces
- Implementação de interfaces
- Classes e objetos
- Construtores
- Métodos
- Enum (`tipoHabilidade`)
